# @fladioarmandika/expo-data-grid

A spreadsheet-style data grid for Expo and React Native, drawn natively: Swift on iOS, Kotlin on Android. Built for 1,000,000 rows × 50 columns with a frozen header, frozen left columns and native sorting.

Work in progress. The repository is at Milestone 0: a spike comparing rendering approaches on real devices. See [SPIKE.md](SPIKE.md) for what's being measured and how to run it.

Requires Expo SDK 58, React Native 0.88 with the New Architecture, iOS 16.4+ and Android API 24+.
